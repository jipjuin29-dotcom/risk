⚠️ AI 위험성평가 자동화

사진을 올리면 AI가 위험요인을 찾아 표시합니다 · 위험성 = 빈도(1~4) × 강도(1~5)
🔧 아직 AI 키가 연결되지 않아 데모 모드로 동작합니다. [평가]를 누르면 예시 결과가 표시됩니다.
✅ AI 키가 연결되어 있습니다. 실제 AI 평가가 동작합니다.
🔑 Gemini AI 키 연결
① 구글 AI 스튜디오(aistudio.google.com)에 구글 계정으로 로그인 → ② [Get API key] → [API 키 만들기] → ③ 만들어진 키(AIza 또는 AQ.로 시작)를 복사해 아래에 붙여넣으세요. 무료입니다.
키는 이 브라우저에 저장되며, 평가 시 사진·현장정보와 함께 Google AI 서비스에 전송됩니다.
🌤 기상청 API 키 연결 선택
① 공공데이터포털(data.go.kr) 로그인 → ② "기상청_단기예보 ((구)_동네예보) 조회서비스" 검색 → [활용신청] (보통 즉시 승인) → ③ 마이페이지 → 해당 서비스의 일반 인증키(Decoding)를 복사해 아래에 붙여넣으세요.
키를 넣으면 [🌤 자동] 버튼이 기상청 초단기실황을 가져오고, 키가 없으면 Open-Meteo(국제 기상모델) 값으로 대신 표시됩니다.
